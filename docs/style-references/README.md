# Style References

Place optional screenshots or visual references here when asking an agent to use Resume2Site-Skill.

- Xiaohongshu screenshots.
- GitHub portfolio templates.
- Dribbble or Behance shots.

- Layout rhythm.
- Typography mood.
- Color direction.
- Visual density.
- Section structure.
