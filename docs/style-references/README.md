# Style References

This folder is optional.

Resume2Site-Skill already includes built-in academic and landing-page style distillation. Users do not need to provide screenshots for the Skill to produce a polished result.

Place screenshots or visual references here only when you want the agent to adapt the built-in style toward a specific mood.

Useful sources include:

- Xiaohongshu screenshots.
- GitHub portfolio templates.
- Dribbble or Behance shots.
- Academic homepages.
- Personal landing pages.
- Product portfolio pages.

The agent may analyze these files for supplemental inspiration:

- Layout rhythm.
- Typography mood.
- Color direction.
- Visual density.
- Section structure.
- Asset treatment.

The agent must not copy exact layouts, proprietary artwork, brand systems, or identifiable designs. Built-in Skill rules remain the baseline.
