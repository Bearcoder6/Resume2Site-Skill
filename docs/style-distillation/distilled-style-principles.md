# Distilled Style Principles

These are built-in design principles distilled before release. Users do not need to perform this research themselves. Agents should apply these principles by default, then optionally adapt them to user-provided screenshots or style notes.

## Principle 1: Start With Identity

The first viewport must make the person's name, role, and intended audience obvious.

## Principle 2: Facts Before Flourish

The site should become more polished after structured extraction, not by inventing better facts.

## Principle 3: Match Mode To Audience

Academic pages need credibility and scan-friendly scholarly structure. Landing pages need strong positioning, selected work, and clear CTA.

## Principle 4: Make Academic Pages Feel Scholarly

Academic pages should use restrained editorial structure: profile sidebar, readable publication lists, quiet borders, serious typography, and subtle research/campus/library atmosphere.

## Principle 5: Make Landing Pages Feel Commercially Polished

Landing pages should use a stronger hero, concrete positioning, selected work cards, clear CTA, domain-aware color, and a confident visual rhythm without fake metrics or generic SaaS patterns.

## Principle 6: Use Visual Assets Deliberately

Images, textures, and patterns should support the person. Use free/open/licensed assets only after checking terms and recording credits. If licensing or relevance is unclear, prefer CSS-only visuals.

## Principle 7: Polish The Shape

Spacing, typography, section rhythm, asset treatment, and mobile behavior matter as much as content. The page should feel intentionally designed.

## Principle 8: Publish Safely

Public output should contain only what the user would reasonably want online.
