# UI Patterns Research

These patterns are useful when generating static personal websites.

## Shared Patterns

- First-viewport identity signal.
- Section anchors for scannability.
- Alternating content rhythm without excessive card nesting.
- Clear link affordances.
- Responsive grid that becomes a single column on mobile.
- Stable image containers that avoid awkward cropping.
- Asset credits when visual assets are used.

## Academic Patterns

- Sidebar or profile card.
- Publication list with action links.
- Research interest chips or short descriptions.
- News list with dates.
- Compact education and honors.

## Landing Patterns

- Hero with CTA.
- Strength cards.
- Project case-study cards.
- Experience highlights.
- Contact band.
