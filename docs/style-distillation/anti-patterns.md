# Anti-Patterns

Avoid these when using Resume2Site-Skill.

## Content Anti-Patterns

- Directly converting resume bullets into HTML.
- Inventing metrics or impact.
- Inventing papers, awards, affiliations, or testimonials.
- Keeping weak phrases like "passionate developer" or "hard-working student".
- Showing empty sections.

## Visual Anti-Patterns

- Generic AI gradient hero.
- Stock-photo people unrelated to the user.
- Excessive icons.
- Nested cards everywhere.
- Tiny unreadable publication entries.
- Overly commercial academic pages.
- Landing pages that look like SaaS templates instead of personal sites.

## Privacy Anti-Patterns

- Copying raw resumes into `output/site/`.
- Hiding raw text in HTML comments.
- Publishing phone numbers by default.
- Publishing home addresses.
- Including internal notes or extraction logs.
