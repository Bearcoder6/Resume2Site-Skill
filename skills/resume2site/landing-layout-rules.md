# Landing Layout Rules

Use landing mode for job seekers, product managers, designers, developers, creators, freelancers, and personal-brand users.

## Default Structure

```text
Hero
Personal Positioning
Core Strengths
Selected Projects / Works
Experience Highlights
Skills
Contact CTA
Resume Download
```

Omit sections with no real content.

## Visual Style

- Polished and modern.
- Personal-brand oriented.
- Stronger hero than academic mode.
- Clear CTA.
- Expressive but tasteful.
- No generic AI SaaS look.
- No fake testimonials.
- No fake numbers.
- No stock-photo cliche.

## Content Emphasis

- Hero should communicate name, target role, and credible value.
- Strengths should be concrete and supported by resume facts.
- Projects should read as selected case studies.
- CTA should match the user's goal: interview, portfolio, collaboration, GitHub, or email.
