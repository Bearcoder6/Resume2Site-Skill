# Academic Profile Template

Use this as a reference, not a fixed framework.

Generate a static site with:

```text
output/site/index.html
output/site/styles.css
output/site/assets/
output/site/README.md
output/site/.nojekyll
output/site/ASSET_CREDITS.md
```

The HTML should be semantic and simple enough for GitHub Pages. Use plain HTML/CSS unless the user asks for a framework.

Recommended HTML landmarks:

```html
<header>
<main>
<aside>
<section id="about">
<section id="research">
<section id="publications">
<section id="projects">
<section id="awards">
<section id="contact">
```

Do not include empty sections.
