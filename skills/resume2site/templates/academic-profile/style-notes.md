# Academic Profile Style Notes

- Use restrained editorial design.
- Prefer white, off-white, slate, ink, soft blue, muted green, or warm gray.
- Use subtle borders and section dividers.
- Keep the publication section highly readable.
- Use a profile photo only if the user provides one or extraction is reliable.
- Avoid huge hero slogans.
- Avoid commercial CTA language.
- Use small but meaningful links: PDF, code, project, Scholar, DOI, arXiv.
