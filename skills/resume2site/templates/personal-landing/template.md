# Personal Landing Template

Use this as a reference, not a fixed framework.

Generate a static GitHub Pages site with:

```text
output/site/index.html
output/site/styles.css
output/site/assets/
output/site/README.md
output/site/.nojekyll
output/site/ASSET_CREDITS.md
```

Recommended HTML landmarks:

```html
<header>
<main>
<section id="hero">
<section id="positioning">
<section id="strengths">
<section id="work">
<section id="experience">
<section id="skills">
<section id="contact">
```

Do not include empty sections.
