# Personal Landing Style Notes

- Use a stronger visual identity than academic mode.
- Select a palette that matches the person's field.
- Use expressive typography, layout rhythm, and imagery, but keep it tasteful.
- Avoid generic SaaS gradients and fake startup metrics.
- Make CTA buttons practical: Email, GitHub, Portfolio, Resume, LinkedIn.
- Project cards should look like selected works, not copied resume bullets.
- Ensure mobile layout keeps the hero and CTA readable.
