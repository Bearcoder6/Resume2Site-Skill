# Visual Polish Pass Prompt

Use this prompt after initial HTML/CSS generation.

## Review

Check:

- First viewport identity and positioning.
- Typography hierarchy.
- Color palette coherence.
- Section rhythm.
- Card and border consistency.
- Mobile readability.
- Image cropping and asset fit.
- CTA clarity.
- Empty or thin sections.
- Whether the page feels like a designed personal site rather than a resume.

## Improve

Make one focused polish pass:

- Tighten spacing.
- Improve headings.
- Replace generic labels.
- Strengthen visual hierarchy.
- Remove weak decorative clutter.
- Adjust mobile layout.
- Improve project/publication card formatting.

Do not add invented facts during polish.
