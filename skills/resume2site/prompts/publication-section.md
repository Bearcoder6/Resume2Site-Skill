# Publication Section Prompt

Use this prompt for academic mode when papers are present.

## Read

- `work/profile.json` papers.
- Paper links, DOI links, arXiv links, or user-provided summaries.

## Output

For each selected publication:

```text
Title
Authors
Venue / Year
Contribution summary
Links
```

## Rules

- Do not invent venues, acceptance status, authors, or contribution claims.
- Mark preprints clearly when appropriate.
- Keep formatting consistent.
- If paper metadata is incomplete, include only verified fields.
- Prefer a concise contribution summary over abstract-like verbosity.
