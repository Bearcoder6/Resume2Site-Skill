# Resume2Site-Skill

This repository is a lightweight Agent Skill package.

Primary skill entry:

```text
skills/resume2site/SKILL.md
```

Use that file when an agent needs to convert a resume, GitHub projects, papers, and optional style references into a polished GitHub Pages-ready personal website.

This repository is not a CLI, parser, crawler, SaaS app, Python package, npm package, or full website builder. It provides workflow rules, prompt templates, design rules, privacy guidance, examples, and final review criteria for coding agents.
